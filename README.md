# 📊 Análisis de Datos - Alura Store Latam

## 📖 Descripción del Proyecto

Este proyecto tiene como objetivo realizar un análisis exploratorio de datos utilizando Python para comprender el desempeño comercial de las tiendas de **Alura Store**.

A partir de cuatro bases de datos correspondientes a diferentes tiendas, se analizaron distintos indicadores clave como:

* Facturación total por tienda
* Categorías de productos más vendidas
* Calificación promedio de los clientes
* Productos más y menos vendidos
* Costo promedio de envío

El análisis se desarrolló utilizando **Python**, junto con las bibliotecas **Pandas** para la manipulación de datos y **Matplotlib** para la visualización gráfica.

El objetivo principal es identificar patrones en las ventas y obtener insights que puedan apoyar la toma de decisiones comerciales basadas en datos.

---

## 🛠 Tecnologías utilizadas

* Python
* Pandas
* Matplotlib
* Google Colab
* Jupyter Notebook

---

## 📂 Estructura del análisis

El proyecto se desarrolló siguiendo las siguientes etapas:

1. **Importación de datos**
   Se cargaron las bases de datos de las cuatro tiendas directamente desde el repositorio.

2. **Análisis de facturación**
   Se calculó el total de ingresos generados por cada tienda para comparar su rendimiento comercial.

3. **Ventas por categoría**
   Se identificaron las categorías de productos con mayor volumen de ventas.

4. **Calificación promedio de clientes**
   Se analizó el nivel de satisfacción del cliente en cada tienda.

5. **Productos más y menos vendidos**
   Se identificaron los productos con mayor y menor demanda.

6. **Costo promedio de envío**
   Se evaluó el costo logístico promedio asociado a las ventas.

7. **Visualización de datos**
   Se desarrollaron gráficos para facilitar la interpretación de los resultados.

---

## 📈 Principales resultados del análisis

A partir del análisis de los datos se identificaron los siguientes hallazgos:

* Existen diferencias claras en la **facturación total entre las tiendas**, lo que permite identificar cuáles presentan un mejor desempeño comercial.
* Algunas **categorías de productos concentran la mayor parte de las ventas**, lo que sugiere oportunidades para optimizar estrategias de inventario y marketing.
* Las **calificaciones promedio de los clientes** permiten evaluar la experiencia del usuario y detectar posibles oportunidades de mejora en el servicio.
* El análisis de **productos más y menos vendidos** aporta información relevante para la gestión del catálogo de productos.
* El **costo promedio de envío** puede influir en la competitividad de cada tienda y en la decisión de compra de los clientes.

---

## 🧠 Interpretación de los datos

Los resultados del análisis permiten obtener una visión general del comportamiento de las ventas en las distintas tiendas de Alura Store.

La comparación entre tiendas evidencia que algunas unidades presentan un mayor rendimiento en términos de ingresos, lo cual puede estar relacionado con factores como la demanda de ciertas categorías de productos, estrategias comerciales o experiencia del cliente.

Asimismo, identificar las categorías con mayor volumen de ventas permite orientar decisiones estratégicas relacionadas con la gestión del inventario, promociones y campañas de marketing.

La evaluación de las calificaciones de los clientes también aporta información relevante sobre la percepción del servicio, lo cual es fundamental para mantener la satisfacción y fidelización de los consumidores.

En conjunto, el análisis demuestra cómo el uso de herramientas de análisis de datos puede contribuir a una **toma de decisiones más informada**, permitiendo optimizar la operación comercial y mejorar la experiencia del cliente.
